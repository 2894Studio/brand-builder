Fortalezas y riesgos con el mismo rigor.

## Checklist de revisión

Recórrela antes de entregar y escribe fortalezas y riesgos con el mismo rigor.

**Estrategia**
- [ ] El posicionamiento se puede decir en una frase y no sirve para un competidor.
- [ ] Promesa y expresión visual no se contradicen (accesible frente a exclusivo).
- [ ] Los valores dicen algo que afecta a una decisión.

**Identidad**
- [ ] El logo pasa las seis preguntas de `identidad/references/logo.md`.
- [ ] Están las cinco versiones del logo y el archivo vectorial.
- [ ] La paleta tiene papel asignado por color y contrastes comprobados.
- [ ] Las tipografías están licenciadas y aplicadas de verdad, no solo nombradas.

**Sistema**
- [ ] Las láminas pasan la revisión de `laminas/references/sistema-laminas.md`, sección 8.
- [ ] Hay reglas de uso, no solo muestras bonitas.
- [ ] Las aplicaciones cubren los soportes que el cliente dijo que usaba.

**Riesgos**
- [ ] Anterioridades del nombre comprobadas o señaladas como pendientes.
- [ ] Claims revisados y los dudosos marcados.
- [ ] Las imágenes generadas están identificadas como referencia, no como material final.
- [ ] Está escrito qué falta y quién lo tiene que hacer.
