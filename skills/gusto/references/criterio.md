# Criterio para juzgar una pieza (lo que mira el modelo tras el crítico mecánico)

El crítico encuentra defectos; no sabe si la pieza vale. Estas cinco preguntas, con la captura delante:

1. **¿Qué se lee primero, segundo y tercero?** Si dudas, la jerarquía no está decidida.
2. **¿Cuál es la prueba?** Una cifra con fuente, una persona con rol o una pieza de interfaz. Sin prueba es un eslogan.
3. **¿Qué tono domina?** Debe corresponderse con la proporción de `gusto.json`.
4. **¿Qué parecería igual con otro nombre?** Si la pieza vale para cualquier competidor cambiando el logo, está mal.
5. **¿Qué es de mentira?** Foto marcador, nombre de ejemplo, dato inventado. Debe verse como ejemplo y figurar en la entrega.

Señales de plantilla: todas las cajas del mismo tamaño, avatares genéricos, iconos de librería sin relación con el mensaje, tres columnas iguales sin jerarquía, un degradado sin función, mucho aire sin intención.
