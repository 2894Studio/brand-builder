# Tipografía

Dos familias, contraste real entre registros, licencia comprobada. El paso manual sobre el logotipo está en `entrega/references/a-mano.md`.

## Tipografía

- **Dos familias**: una para títulos y otra para texto. Una sola familia con varios pesos también es una respuesta válida y más fácil de sostener.
- Emparejamientos que funcionan: serif con personalidad + sans neutra · sans geométrica + serif de texto · superfamilia (serif y sans de la misma familia) para máxima coherencia.
- No emparejes dos fuentes del mismo registro: dos sans humanistas parecidas se leen como un error, no como una decisión.
- Comprueba: números, versalitas, acentos y la eñe. Una fuente sin eñe decente no sirve en español.
- **Licencia**: comprueba que permite uso comercial, web y producto. Es el paso que más se olvida.
- Para marcas de oficio, las serifs con contraste o las de estilo antiguo refuerzan el mensaje; las grotescas puras lo neutralizan.
